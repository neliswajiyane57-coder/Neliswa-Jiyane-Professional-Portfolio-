# Project Nexus — Neliswa Jiyane Portfolio

A premium, single-page personal brand site built with semantic HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Before publishing

- Add the CV as `assets/resume/Neliswa_Jiyane_CV.pdf`.
- Add the credentials bundle as `assets/resume/Neliswa_Jiyane_Credentials.pdf`.
- Replace the placeholder certificate cards with official credential images/files in `assets/certificates`.
- Update the LinkedIn, GitHub and email links in `index.html`.

The project is ready to deploy to GitHub Pages once those personal links and files are supplied.
